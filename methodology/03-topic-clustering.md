# 方法论 · 03 痛点聚类

> 从评论里提取"玩家到底在抱怨什么",并且**让结论可复核**。

## 核心原则：词典负责召回，人工负责裁决

关键词匹配永远会有误差。**不要假装它是完美的。**

## 步骤

### 1. 建词典（分四类）

```python
CATEGORIES = {
    "操作手感": ["卡", "延迟", "掉帧", "失灵", "判定", "碰撞", "操作"],
    "性能卡顿": ["卡顿", "卡死", "闪退", "加载", "掉帧", "卡"],
    "内容深度": ["单调", "无聊", "简单", "重复", "缺少", "太少"],
    "关卡设计": ["难度", "太难", "太简单", "死", "卡关", "地图", "路线"],
}
```

注意「卡」同时属于操作手感和性能卡顿 —— **允许重叠，最后人工分配**。
实现上会记录每条评论命中的所有类别（`overlap`），主类别按「最长关键词优先」
选择：命中「卡顿」归入性能，命中「卡」归入操作手感，避免泛词吃掉具体词。

### 2. 跑匹配 + 人工复核

```python
matched = {c: [d for d in real_neg if any(k in d["content"] for k in kws)]
           for c, kws in CATEGORIES.items()}
```

然后**逐条读未命中的评论**，补充词典后重跑。

### 3. 必须报告未命中率

```
字典命中: 201/256 (78.5%)
未命中: 55 条 (21.5%) ← 必须人工读一遍
```

**未命中率 > 30% 说明词典有问题，不要直接出结论。**

## 关键：否定语义陷阱

`"不卡"`、`"没有闪退"`、`"没有bug"` —— 关键词能命中，但**语义是正面**。

```python
NEGATED_DEFECTS = {"不卡", "不卡顿", "不闪退", "没有bug", "不掉帧", "不无聊"}
```

处理方式：**先移除「缺陷被否定」的短语，再做关键词匹配**。

```python
text = "一点都不卡，但按钮点不动"
text = _strip_negated_defects(text)   # → "一点都不 ，但按钮点不动"
# 「卡」不再命中；「按钮」仍然命中 ui与交互
```

**不要整句丢弃。** 早期实现只要评论里出现「不错 / 还行 / 没难度」就把整条
从类别里删掉，结果是「画面不错但太卡」这类混合评价被静默丢弃，
覆盖率还把这条算作已覆盖 —— 既漏痛点，又虚报覆盖率。

还要注意：`"没难度"`、`"不好玩"` 仍然是**差评**（只是换了一个维度），
不能当成正面表述。否定表只收「缺陷被否定后变成好评」的短语。

## 抽样复核（防止过拟合）

从每个痛点类随机抽 3 条，念给不知道分类的人听。

如果对方会分到别的类 → 词典边界不清，需要修。

## 领域词典扩展（关键机制）

**通用词典必然漏掉领域特有词汇。** 实测（象棋案例）：

| 阶段 | 覆盖率 | 说明 |
|---|---|---|
| 初版通用词典 | **31.5%** | 漏掉整个「规则与玩法」类别 |
| 扩充通用词典 | 58.8% | 加了超时/判负/匹配/单人等词 |
| ＋领域词典 | **75.5%** | 补象棋术语（将军/照脸/炮/将） |

### 为什么必须外置

如果把「炮、马、卒、将军」直接写进通用词典，这个项目就只能用于象棋 —— **可迁移性归零**。

正确做法：通用词典保持稳定，领域词放外部 JSON。

```json
{
  "category": "规则与玩法",
  "keywords": ["将军", "照脸", "炮", "马", "卒", "怎么玩", "哪方赢"],
  "ignore": ["**", "***", "傻", "滚"]
}
```

```bash
python analyze.py --level-id xxx --domain-lexicon my_domain.json
```

### `ignore` 列表：纯辱骂单独归类

「**游戏」「我***的」这类没有产品信息量。**混进功能类别会污染痛点排序** —— 它们会让"规则与玩法"虚高。

所以：

```python
if any(w in text for w in ignore):
    emotional.append(d)   # 单独归类，不进功能桶
    continue
```

**并且覆盖率的分母要排除它们** —— 它们本来就不该被归类。

> 修正后：未命中 51 条 / 纯情绪 8 条 / 可归类 208 条 → 覆盖率 75.5%
> （若把纯情绪计入分母，会虚报成 68.5%）

## 词典不能塞什么

- ❌ 纯情绪词（"垃圾""恶心"）—— 塞进功能类别会污染排序，应放 `ignore`
- ❌ 领域术语进通用词典 —— 破坏可迁移性
- ❌ 泛化过度的词（"没有""不能"）—— 命中率虚高但无信息量

## 报告呈现

不要只给数字，要给**原话**：

```
规则与玩法 · 98 条 (45.4%)
  代表评论：
  · "能不能加一个长将犯规啊，本来我必赢的，但是对面一直将"   ← 2026-06-20
```

原话是唯一能让人相信你的分析的东西。

**注意**：「规则与玩法」能占到 45.4%，靠的不是通用词典，而是领域词典 + 人工复核。
只跑通用词典的话，这个核心结论会被完全漏掉。
