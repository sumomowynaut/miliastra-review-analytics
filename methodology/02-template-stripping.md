# 方法论 · 02 模板语剥离（核心）

> UGC 评论区普遍存在"用户勾选即自动附带"的默认文案。**不剥离会让所有体验结论失真。**

## 问题

玩家提交评论时，通常是勾选「好评 / 差评」+ 可选地写点文字。

平台会在勾选时**自动附上一段固定文案**，用户一个字都没打。

结果：这些零信息量的评论混在数据流里，**把好评率和差评率都往中间拉**。

## 实测危害（`50105539813`，1532 条）

| 模板文案 | 条数 | 占比 |
|---|---|---|
| `非常优秀的奇域，推荐大家游玩~` | 725 | 占全部好评 **59.8%** |
| `奇域仍有待打磨，期待作者的更新~` | 104 | 占全部差评 **32.6%** |
| **合计** | **829** | **占总评论 54.1%** |

剥离前后对比：

| 指标 | 表观（含模板） | 真实（剥离后） | 差异 |
|---|---|---|---|
| 好评率 | 79.2% | **69.3%** | −9.9pt |
| 差评率 | 20.8% | **30.7%** | +9.9pt |
| 近30天差评率 | 27.4% | **42.0%** | **+14.6pt** |
| 5月 → 10月差评率 | 7.9% → 26.7% | **13.9% → 42.2%** | **趋势从"缓升"变"翻三倍"** |

**官方公布的 79.2% 好评率是含模板口径** —— 它和本地算的一致（校验通过），但**不能用来判断真实体验**。

## 铁律

1. **不要预设文案，从数据里挖**
2. **命中率必须验证**，剥离后检查唯一文本数
3. **双口径都要报**：表观对齐官方，真实用于结论
4. **代表评论必须从真实评论里选**
5. **所有分布类统计都用真实评论**
6. **报告里显式说明已剥离**，否则读者会以为算错了

## 一、自动探测模板（不硬编码）

```python
import re
from collections import Counter

def normalize(s):
    """归一化标点，抓到带/不带 ~ 的变体"""
    return re.sub(r'[~～。，,！!？?、\s]', '', s or '')

def detect_templates(details, min_count=8, max_len=60):
    """高频完全重复 = 疑似模板"""
    counter = Counter(normalize(d["content"]) for d in details)
    templates = []
    for text, n in counter.most_common(50):
        if n < min_count: break
        if len(text) > max_len: continue
        # 模板通常是完整句子；排除纯数字/单字
        if len(text) < 6: continue
        templates.append((text, n))
    return templates
```

### 启发式依据

- 模板的**重复率接近 100%**（729 条全是同一句）
- 真实评论重复率很低（703 条 → 675 种唯一文本，**重复率 4%**）

### 局限性 ⚠️

- 短词可能误判（"好玩""好"重复 7-9 次）
- 需要人工确认每一条
- 只抓完全一致，可能漏掉同类但措辞不同的模板

## 二、剥离

```python
# 支持用户补充（同一平台不同奇域模板可能不同）
TEMPLATES = set(detect_templates(details)) | user_supplied_templates

def is_template(text):
    return normalize(text) in TEMPLATES

for d in details:
    d["is_template"] = is_template(d["content"])

raw   = details                      # 表观：用于对齐官方口径
real  = [d for d in details if not d["is_template"]]
```

## 三、验证剥干净了

```python
uniq = len({normalize(d["content"]) for d in real})
dup_rate = 100 - uniq / len(real) * 100
print(f"{len(real)} 条真实评论 → {uniq} 种唯一文本，重复率 {dup_rate:.1f}%")
# 实测 703 → 675，重复率 4% ✅
```

**若真实评论仍有大量重复，说明还有变体没挖到，回去继续探测。**

## 四、必须同步改造的下游

| 位置 | 改法 | 漏了会怎样 |
|---|---|---|
| 主题聚类 | 代表评论、排序只用 `real_neg` | 榜单被模板占满 |
| 痛点占比 | 分母从 `len(neg)` → `len(real_neg)` | 占比虚高 |
| 时段/星期/IP/用户分布 | 全部基于 `real` | 分布被冲淡 |
| 高赞好评 TOP | 排除模板 | 刷屏同一句话 |
| 月度趋势 | 双口径并列 | 看不出真实恶化 |

## 真实教训

曾用表观口径分析某奇域，得出"差评率 26.7%，体验下滑但尚可接受"。

剥离模板后真实差评率 **42.2%** —— 结论从"需关注"变成"严重恶化"。

**没有剥离的评论分析，基本没有价值。**
