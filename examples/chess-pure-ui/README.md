## 这个案例说明了什么

1. **表观好评率会产生误导。** 官方公布的 79.2% 是含模板口径，与本地计算一致
   （可用于校验数据完整性），但不能用于判断真实体验 —— 真实差评率高出 9.9pt。
2. **通用词典无法覆盖核心痛点。** 「规则与玩法」占 45.4%，是最大问题；
   初版通用词典覆盖率仅 31.5%，完全没有覆盖这一类。加入领域词典后升至 75.5%。
3. **趋势结论必须看绝对量。** 差评占比与差评绝对量必须并排，分母变化会显著改变结论。
